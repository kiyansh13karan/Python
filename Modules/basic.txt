Modules in Python :- 

In Python, a module is simply a file containing Python code (with a .py extension) that can define functions, classes, and variables, and can also include runnable code.

Think of a module as a toolbox that you can use in your own programs to avoid writing the same code again.



Why Use Modules ? 

Reusability – Write once, use anywhere.
Organization – Keep related code together.
Simplicity – Break large programs into smaller, manageable pieces.
Built-in functions – Use Python’s powerful standard library.



Types of modules :- 

Built-in Modules – Already available in Python (e.g., math, random, os, datetime)
User-defined Modules – Written by you or someone else (your own .py files)
Third-party Modules – Installed using pip (e.g., numpy, pandas, requests)
